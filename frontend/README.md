# StockForge frontend

React + Vite. See [the project README](../README.md) for setup, permissions, completed features, and the review checklist.

- `npm run dev`: development server
- `npm run lint`: ESLint checks
- `npm run build`: production build
- `npm run preview`: preview the production build (set the backend FRONTEND_URL to match its origin)

Set `VITE_API_URL` to the API base URL, including `/api`. The default is `http://localhost:5000/api`.
